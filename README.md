# 레니게이드 플레티넘 도감 v17

## 실행

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## v17 변경 사항

- 이벤트로만 얻는 포켓몬은 출현 지역 목록에서 제외하고, 선물/특수 이벤트 영역에만 표시합니다.
- GiFTSEVENTS 시트의 포털/전설/환상 이벤트 상세 문장을 다시 파싱했습니다.
- 스이쿤은 213번도로 포털 조우 이벤트로 표시됩니다.
- 기술명 변경: 혼내기 → 더블촙
- 손바닥치기 위력 변경: 15 → 25
- 특성 변경 반영: 대짱이 쓱쓱, 나무킹 색안경, 초염몽 스킬링크, 엘레이드 적응력, 엠페르트 클리어바디

## 폰트

폰트 파일은 라이선스 문제로 포함하지 않았습니다. 사용할 권한이 있는 `pokemon-dppt.otf`를 아래 경로에 직접 넣어 주세요.

```text
assets/fonts/pokemon-dppt.otf
```
